# Private configuration inputs

This example is a structural reference, deliberately not a runnable substitute for the owner's exact restore Compose. The actual complete deployable configuration is `BTCML_BACKUP_071126/RESTORE/compose.restore.private.json`, with all mounts, source/admission/policy bindings, Docker socket group, volume subpaths, budgets and environment. No secret values, financial approvals, mutable runtime data or fake descriptor are distributed in Git.

For every role use its saved environment from the private inventory; do not invent defaults for missing source permissions or replace missing configuration with a market WAIT. Runtime files are copied to a separate writable tree. Historical financial provenance is not rewritten. Installed sources are role-specific and must not be flattened into an arbitrary old working tree.

The source snapshot and compiled image have different identities. Cognition's original image metadata was absent; its reconstructed restore image is documented separately. These templates do not authorize OPEN, skip recovery offsets, enable REAL or replace exact private manifests.
